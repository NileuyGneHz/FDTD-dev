## 3. 诊断：wide_angle.fsp 有 A，wd_BFASK.fsp 没有（用户提问）

**用户猜「A 没有自动绑定到 model 上」—— 方向正确，根因已定位并实测。**

FDTD 的 **O&S "model" 就是对象树根 `::model`**，它带 `setup script` / `analysis script` 两个属性；
**结果名 = `analysis script` 里 `matrixdataset("<名>")` 的名字**。

| 项 | `wide_angle.fsp`（有 A） | `wd_BFASK.fsp`（没有 A） |
|---|---|---|
| 根 `setup script` | 空 | **把"算 A"整段塞进来了（放错槽位）** |
| 根 `analysis script` | 输出 `matrixdataset("A")` | 输出 `matrixdataset("Absorption")`（名字被改） |
| 根 `results` | `['A']` | `['']` |
| 树中 `A` 对象 | 无 | 多一个 `A` **Analysis Group**（多余） |

**附带发现**：那个多余的 `A` 分析组会让 `runanalysis` **整体失败**
（`one or more analysis objects encountered errors`，因组作用域读不到组外监视器）；
删掉它立刻恢复。另：`runanalysis()` **不执行**根 analysis script，
根脚本由 **O&S（`runsweep`）** 触发。

**未验证**：headless `addsweep`+`runsweep` 启动了 30 点扫描（完成 4 点），
