## 2. WhaleNote 第 5 条：狄拉克锥的维度问题

用户提问：**"狄拉克锥不是三维结构吗？为什么能和二维的石墨烯扯上关系？"**

- 这是一个**实空间 vs 动量空间**的概念混淆，很有价值，值得单列一条。
- 核心答案：锥是 **E(kx, ky) 二元函数的曲面**（3 轴 = 2 自变量 + 1 函数值），
  三根轴里**没有一根是实空间的 z**；石墨烯在 z 方向被量子化、无 kz 色散。
- 补了两个有力的论证：
  1. **反证**：3D 材料的能带要 4 根轴，画不出来 —— 石墨烯能用一张图完整画出，
     恰恰因为它二维。
  2. **定量**：线性色散下 D(E) ∝ E^(d−1)。d=2 → D∝E（石墨烯）；d=3（Dirac 半金属）→ D∝E²。
     所以"二维"不是措辞问题，直接决定态密度指数，进而决定 n ∝ μ_c² 与栅压调控效率。
- 顺带澄清：条目 1 里那张"X 形"能带图**不是简化画错**，而是锥沿 kx 的**一维截面**。
- 内联图：左「实空间 2D 蜂窝晶格 + z 箭头」/ 右「k 空间双锥，轴为 kx、ky、E」。
- 脚本归档：`_scratch\archive\2026-10-10_whale\whale_honeycomb.py`。

## 4. Lumerical GUI 打不开：license vendor daemon 挂了（已修复）

**报错**：`Failed to checkout feature 'lumerical_gui'` / `The desired vendor daemon is down` /
`FlexNet Licensing error:-97,121`。

**诊断结论**：许可服务器是**两段进程链** —— `lmgrd`（broker）+ `ansyslmd`（vendor daemon）。
实测 `lmstat -a` 显示 `license server UP v11.19.5` 但
`ansyslmd: Network connect to THIS_HOST failed. (-95,378)`；
`tasklist` 确认 `lmgrd.exe` 在跑、**`ansyslmd.exe` 缺失**。
→ **-97 不是"许可服务器挂了"，是"broker 活着、vendor daemon 死了"。**
配置、许可路径、客户端设置都没问题，**不要去重跑许可向导**。

**修复**（无需管理员，已在本机执行并验证）：

```
"F:\Lumercial\Shared Files\fnp\winx64\lmutil.exe" lmreread -c 1055@localhost
```

返回 `lmreread successful`；随后 `ansyslmd.exe`（PID 18940）起来，`lmstat` 显示
`ansyslmd: UP v11.19.5`，且 `lumerical_gui` / `lum_fdtd_gui` / `lum_interconnect_gui` /
`lumerical_solve` 各 100 席可用。

**根因（推断，未刻意复现）**：`.lic` 的 hostid 绑定在**有线 Realtek 网卡**
（`SERVER localhost 047c1636fd0f 1055` ↔ `04-7C-16-36-FD-0F`），该网卡当前为
「媒体已断开连接」。开机时若服务先于网络栈就绪、或该网卡被禁用，
vendor daemon 可能过不了 hostid 校验而死，而 `lmgrd` 过了同一校验活下来。

**预防**：① 不要禁用有线 Realtek 网卡（VMware / Radmin VPN 网卡与许可无关）；
② 把 `ANSYS, Inc. License Manager CVD` 改为**自动（延迟启动）**；
③ 复发时直接跑下面的一键脚本。
