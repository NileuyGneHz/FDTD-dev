## 1. 原理总表

## 2. 广义惠更斯条件的推导链（式 1–4，p.3）

```
E(ẑ)   = E_even(ẑ) + E_odd(ẑ)          前向散射
E(−ẑ)  = E_even(ẑ) − E_odd(ẑ)          后向散射（偶分量不变号、奇分量变号）

T = |1 + E_even + E_odd|²               (1)
R = |E_even − E_odd|²                   (2)
1 + E_even + E_odd = e^{iφ}             (3)  ← 无损耗且透射相位为 φ
E_even = E_odd = ½(e^{iφ} − 1)          (4)  ← 反射为零的充要条件
```

- `φ = 0` ⇒ `E_even = E_odd = 0` ⇒ `T = 1, R = 0`：一块透明无反射的窗。
- `φ = π`（HWP 的一支）⇒ `E_even = E_odd = −1` ⇒ `T = |1−1−1|² = 1, R = 0`：**相位翻转 π 而仍全透**，这正是半波片所需。
- 单个电偶极 + 单个磁偶极只能在**一个频率**同时满足 (4)（共振交叉点）；多个多极线性组合把条件从「两共振重合」放宽为「多极平衡」，从而得到宽带。

## 3. 为什么用「高胖纳米柱」而不是薄纳米盘

| 论文论断 | 物理理由 | 本工程参数 |
|---|---|---|
| 柱高须与波长可比 | 柱越高，越高阶的多极模式（HOM）能被容纳；薄片（~200 nm）会截断高阶模式，退回双极窄带情形 | `c = 850 nm ≈ 0.55λ` |
| 周期须亚波长 | `D > λ` 会引入非零衍射级，能量跑出 0 级、偏振纯度与透射崩坏 | `D = 750 nm < 1530 nm` |
| 方晶格 | 补充材料 p.13：方晶格使格林函数 `Ḡ` 的 xy / yx 非对角元为零，x/y 偏振不串扰，Δφ 定义干净 | `period_x = period_y = D`，supercell 1×1 |
| 宽带 vs 窄带 | 补充材料 p.13 S1：宽带 152 nm vs 窄带 19 nm，差 8 倍；两组几何是 `285/450/860/750` 与 `160/470/1080/950` | 主工程用 Fig.3 的 `280/430/850/750`；Fig.2 组另做口径诊断 |

## 4. 本工程对 Mie 共振 / 多极分解的能力边界

论文 Fig. 2(b)(c) 的「多极叠加压低反射」是**用 CST 导出柱内电场后做多极展开**得到的（补充材料 p.13 S4：`J(r) = −iω[ε̄(r)−ε₀]E_CST(r)`），不是 FDTD 的 R 监视器能直接给出的量。

本工程只测 `T / R / E(相位)`，因此：
- ✅ 能验证「宽带低反射、高透射、Δφ 平坦」这些**现象**；
- ❌ 不能验证「低反射确由 ED+MD+HOM 干涉造成」这一**因果机制**。

要做完整因果验证，需要额外导出柱内复电场并做多极矩积分（或切换到与论文一致的 CST + 多极分解流程）。这项列为报告 §5 的阻塞项 `C-2`。
