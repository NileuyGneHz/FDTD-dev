## 2. 逐条展开

### 2.1 正交电偶极子与 45° 分解

设金砖长轴为 u、短轴为 v，二者在 xy 平面内相对 x/y 转 45°。入射 `E_i = E_0 x̂` 投影为

```
E_ui = E_0·cos45° = E_0/√2      (沿长轴)
E_vi = E_0·sin45° = E_0/√2      (沿短轴)
```

**只有 45° 才等分**：若转 30°/60°，两分量幅度不等，合成反射会带椭圆度，`R_co` 残留上升、PCR 下降。
由于 `l1=390 nm ≠ l2=165 nm`，两个方向的局域表面等离激元共振波长被刻意拉开（detuned），
在两共振之间的**失谐平缓区**，「等幅 + Δφ≈π」在很宽波段内同时成立 → 这是宽带（800–1600 nm）的来源。

> 工程体现：`addpoly` 顶点表 `rot_rect(390e-9, 165e-9, 45)`，`addrect` 无旋转属性故禁用。
> 结构沿 x/y 以 `p=600e-9` 周期排列，x/y 设 `Periodic` BC。

### 2.2 等幅 + 相位差 π → 半波片

设两轴反射 `E_u = A e^{iφ_u}`、`E_v = A e^{iφ_v}`，`φ_v − φ_u = π`。转回 xy：

```
E_x ∝ E_u cos45° − E_v sin45° = (A/√2)(e^{iφ_u} − e^{iφ_v})   → 相消（≈0）
E_y ∝ E_u sin45° + E_v cos45° = (A/√2)(e^{iφ_u} + e^{iφ_v})   → 相长
```

相对相位差 π = 半个波长 = **half-wave**，故名半波片。
论文 Fig.3b 的黑实线（相位差）接近 π 就是这条判据的实验/仿真证据。

> 工程体现：`R_co = |⟨Ex⟩|² ≈ 0.006`、`R_cr = |⟨Ey⟩|² ≈ 0.89`（900–1600 nm 均值），
> 即入射 x 偏振几乎全部变成 y 偏振反射。`⟨·⟩` 为监视器面上的空间平均（0 阶傅里叶分量）；
> 周期 600 nm < λ 700–1700 nm，正入射下只有 0 阶传播模，面平均即 0 阶反射系数。

### 2.3 Fabry–Perot 类腔

单层等离激元超表面（如 V 形天线）的入射场与交叉偏振场耦合很弱，效率极低。
加一层连续金膜后，光在金砖层与金膜之间多次往返，构成 FP 型腔：

| 分量 | 腔内叠加 | 结果 |
|---|---|---|
| 交叉偏振 | 建设性干涉 | `R_cr → ≈1` |
| 同偏振 | 破坏性干涉 | `R_co → ≈0` |

150 nm ≫ Au 在近红外的趋肤深度（≈25 nm），所以 `T≈0`，器件被限制为**反射模式**，
论文称此为 hybrid plasmonic modes（电共振对称模 + 磁共振反对称模耦合）。

> 工程体现：`T_bot` 监视器在结构下方，`T` 全程 ≈ −2.7×10⁻⁶（≈0），能量守恒成立；
> 总反射 `R_power ≈ 0.92`（>90%，与论文一致），`R_co+R_cr ≈ 0.897 ≤ 1`，**201 个频点无 R>1**。

### 2.4 PCR 与它的盲区

```
PCR = R_cr / (R_cr + R_co)
WB  = 2(λ_l − λ_s)/(λ_l + λ_s)
```

分母是**已反射的光**，不含被吸收的部分。因此若器件吸收极强、总反射很低，
剩下的一点反射可能全是交叉偏振 → PCR 仍接近 100%，但器件实际不可用。
论文因此**同时报告 `R_cr`（>90% 反射率）**，只用 PCR 会骗人。

> 工程体现：CSV 同时输出 `R_co`、`R_cr`、`PCR`、`R_power`、`T_bot`，图上画 `R=1` 上限线。
> 论文 `λ_s=805 nm, λ_l=1672 nm → WB = 2×867/2477 ≈ 0.700`（≈70%）。

### 2.5 扫 SiO₂ 厚度（腔长）

论文原文：*"The optimal SiO₂ thickness is determined through a parameter sweep using simulations"*
（SI §1 / Fig.S1）。腔长 `ts` 决定往返相位，也就决定在哪个波段满足「等幅 + Δφ≈π」，
同时决定工作带宽。这是论文做到宽带的关键旋钮。

> 工程体现：`sio2_spacer` 为独立 `addrect` 对象（`z span = 110e-9`），改厚度只需改一个属性；
> 本次按 **Reproduce 模式**直接采用论文值，未重跑扫参（盲调参凑结果属造假，项目 L1 明令禁止）。
> 若后续要验证，标准做法：冻结 `p, l1, l2, tm, d`、材料、网格、PML、频点、源，
> 只变 `ts ∈ {90, 100, 110, 120, 130} nm`，比较 900–1600 nm 的 `mean PCR` 与 `mean R_cr`，
> 并设负对照（纯金镜）确认差异来自物理而非网格误差。

### 2.6 反射测量需减背景

反射谱不能直接用监视器的总场：plane wave 是软源，频域场监视器在源上方记录的是
「反射场 + 源的背向辐射 / 数值背景」。标准处置有两条，本工程都做了：

1. **背景扣除**：跑一个把全部几何 `enabled=0` 的空结构参考，`E_ref = E_total − E_bg`；
2. **已知答案对照**：纯金膜（150 nm Au）应给 `|Ex|≈1, |Ey|≈0, R≈0.96–0.98` 且平坦，
   用来一次性排除「归一化 / 源 / 监视器方向 / 单位」四类错误（本机 field-manual §7.2）。

> 工程体现：`run.py --mode bg` 生成空结构参考；`R_power`（功率监视器，Lumerical 已归一化到源功率）
> 与 `R_field`（场平均）互为交叉校验；`R_point` 保留旧 t15 的单点口径作对照。
> 论文实验侧用变角度椭偏仪 + 偏振器/检偏器做归一化，物理含义与此处一致。
