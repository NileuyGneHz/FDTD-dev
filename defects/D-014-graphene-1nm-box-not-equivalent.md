# D-014：1 nm box 不能替代石墨烯的表面电导率（需人裁决 D-2）

**状态**：`unresolved`（**待裁决**，2026-11-10 EXP-34 判 fail 后停在这里，不自行改 D-2）

## 现象

同一几何、同一网格（mesh accuracy 2）只换石墨烯表示，P09 完美吸收器的结论完全不同：

| 组 | 石墨烯 | 网格 | A@3.6 THz | 峰位 | 峰值 A |
|---|---|---|---|---|---|
| 基准 | `Sampled 2D data` 表面电导率 | acc 2 | ≈1.00 | 3.511 THz | 0.99998 |
| 1 nm box（ε 正确） | `Sampled data` ε | acc 2 | **0.009** | 7.100 THz | 0.051 |
| 1 nm box（ε 正确） | 同上 | dy=1 nm override | 未完成（49 min 到 0.68%，引擎 ETA 110 h） | — | — |

判据（Δpeak ≤ 10 GHz、ΔA ≤ 0.01）两条都不达成。

## 两个原因，都被单独量过

1. **材料口径**（已修，D-013）：旧代码把 `n+ik` 灌进收 ε 的属性，引擎再开方，
   石墨烯 ε 从 2611i 变成 51i。修好后 `getindex` 反查 k=51.096 与解析一致。
2. **离散化**（本条的主因）：1 nm 层在 acc 2 的 ~200 nm 网格里被摊薄，
   等效 σ 只剩 ~1/200，所以**修好材料后 A 反而更低**（0.034 → 0.009）。
   要解析 1 nm 就得 dy ≤ 1 nm，而 2D 胞里这会把网格推到 8002×240、dt 被最小格距锁死，
   本机单线程 45 min 只走 0.68%。

## 为什么不是「再调调参数」

- 面电导率是**边界条件**，不需要在法向网格化；1 nm 薄层是**体材料**，必须在法向解析。
  两者在粗网格下不等价是物理事实，不是参数没调好。
- 调 `d` 或 `W` 让 A 凑到 1 属于拟合，违反 `reproduction-contract.md` §5 与 L1 方针。

## 需要人决定的三条路

| 选项 | 代价 | 代价的另一面 |
|---|---|---|
| (a) 回到 `Sampled 2D data` 表面电导率 | 需要 spec 支持「面 + σ 表」这一材料/对象组合 | P09 手建模型已验证能给出 A=1 @3.511 THz；但项目此前把它整条移出了范围 |
| (b) 保留 1 nm box | 每点几十小时机时（GPU/多进程可摊薄） | 与论文的 Δ→0 口径最接近；本轮实测 ETA 110 h/点，不可用于扫参 |
| (c) 2D 材料表 + 面对象 | 需要在 spec 里如实写「面」而非「1 nm 厚」 | 介于两者之间，但语义最容易再次含混 |

本轮**不选**。在裁决前，`graphene_kubo_1nm` 保持可用但标注「需 1 nm 网格覆盖，
2D 胞内不实用」；SKILL.md 已写明这条限制。
