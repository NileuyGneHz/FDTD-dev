# docs/features/specs/ — L3 能力规格

## 职责

一条 FEAT = 一项**可验收的能力**（不是"一个功能点"）。它是 spec / plan / task 的串联锚点。

## 格式

```
FEAT-<NNN>-<slug>.md
```

```md
# FEAT-003 相位提取

## 为什么
功率相同、相位不同的两个器件在 T 曲线上无法区分。

## 行为
给定 spec 与偏振角，输出 phase.csv（lam_um, phase_deg_<pol>, dphi_deg）。

## 验收
- Δφ 在两条收敛网格上偏差 < 0.1π
- |E_zeroth|² 与功率监视器的 T 同阶同趋势
- 与文献值对照有明确出处

## 非目标
不提取多阶衍射；不做全器件相位分布。
```

## 约束

1. **验收条件必须可判定**，且能被脚本或一次人工检查证实。
2. **一条 FEAT 对应一个技能或一段技能流水线**，不写"整个系统"。
3. **写完 FEAT 才写 TASK**；TASK 里引用 FEAT 编号。
4. 行为变更先改 FEAT，再改代码——代码改了 specs 没改 = 未完成。
