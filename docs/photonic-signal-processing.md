# 光计算怎么处理信号

> 这份文档回答一个问题：**光除了"算矩阵乘"，还能对信号做什么？**
> 每一条都有对应的代码验证（`_scratch/optical_filter_test.cpp`、`_scratch/layer_test.cpp`）。
>
> 编制日期：2026-11-12

---

## 0. 一句话

**光处理信号，本质是"用物理结构实现一个线性系统"。**

数字信号处理里你写 `y = H·x`（H 是滤波器/矩阵），
光计算里 H 由**光路结构**决定：

| 你想做的事 | 数字实现 | 光实现 |
|---|---|---|
| 滤波（低通/高通/带通） | FIR/IIR 卷积 | 4f 系统 + 频谱面掩模 |
| 矩阵乘法 | 循环 | MZI 网格 / 衍射层 |
| 傅里叶变换 | FFT 算法 | **一个透镜，光速完成** |
| 相关/卷积 | 乘加循环 | 傅里叶变换 + 乘 + 逆变换 |
| 微分/边缘检测 | 差分算子 | 特定相位掩模 |

**核心洞察**：光不需要"计算"傅里叶变换——**它本来就是**。这是光相对于电子唯一不可替代的优势。

## 1. 机制一：透镜做傅里叶变换（最基础，也最反直觉）

### 物理事实

一个凸透镜，把前焦面的场分布，**在光速下**变成后焦面的傅里叶变换。

$$\text{后焦面} = \mathcal{F}\{\text{前焦面}\}$$

**没有算法，没有迭代，没有 O(N log N)。** 光走过这段距离的时间就是延迟。

### 为什么这能"处理信号"

因为**卷积定理**：

$$\mathcal{F}\{x * h\} = \mathcal{F}\{x\} \cdot \mathcal{F}\{h\}$$

所以想算卷积 $x * h$，可以做：
1. 透镜做 $\mathcal{F}\{x\}$（前焦面 → 后焦面）
2. 在后焦面放一个**透过率 = $\mathcal{F}\{h\}$** 的掩模（这就是 SLM / 超表面 / 固定相位板）
3. 再来一个透镜做逆变换

**这就是 4f 系统**（透镜-掩模-透镜）。它是光域滤波的标准架构。

### 代码验证（已实测通过）

`_scratch/optical_filter_test.cpp` 用纯 C++ 验证了这件事：

```
DFT length L = N + M - 1 = 18  (N=16, M=3)
max |optical - digital| = 0.000000
[check] PASS
```

18 个点全部 diff = 0。**光域（频域乘掩模）与数字域（时域卷积）数学上完全等价。**

### 一个真实的坑（我第一次就踩了）

第一版代码用 `DFT 长度 = N = 16`，结果 `max diff = 0.655`，FAIL。

原因：**循环卷积混叠**。信号长度 16 + 滤波器长度 3 - 1 = 18，但 DFT 只做了 16 点，
尾部绕回头部，混进来了。

**这条对光计算极其重要**：
- 数字域你写 FFT 会自然补零，不容易注意
- 光域的"计算长度"由**物理孔径**决定。孔径不够，能量绕回来 = 混叠
- 所以光域滤波器的设计必须考虑**孔径与信号长度匹配**

> **这是"光计算能不能用"的真实约束之一**，不是理论洁癖。

## 2. 机制二：一层结构做一次矩阵乘（衍射/干涉）

### 物理事实

光穿过一层相位调制面（衍射层 / MZI 网格 / 超表面），
出射场的复振幅 = **输入场 × 该层的传输矩阵**。

$$y = H \cdot x$$

### 与数字的对应

| 数字 | 光 |
|---|---|
| `y[i] += H[i][j] * x[j]` | 光在结构里传播、干涉、叠加 |
| 一次矩阵乘 O(N²) 次乘加 | 一次传播完成，延迟 = 光程/光速 |
| 串行（一次一个 i） | **并行**（所有 i 同时出） |

### 代码验证（已实测通过）

`_scratch/layer_test.cpp`：

```
[unitary layer]
  energy in  = 1
  energy out = 1
[attenuated layer]
  energy out = 0.59
[check]
  unitary conserves energy : PASS
  lossy layer loses energy : PASS
```

**两个关键事实**：
1. **酉层能量守恒**（in=1, out=1）——这是单个 MZI 的物理约束
2. **非酉层能量下降**（0.59）——任意矩阵需要"衰减"这个自由度，
   纯 MZI 网格给不了，所以要用 SVD 拆成「旋转-缩放-旋转」

### 多层堆叠 = 深度网络

一层 = 一次矩阵乘。N 层 = N 次矩阵乘 + N 次非线性。
这就是 P06 的 TDONN（1 输入 + 5 隐藏 + 1 输出 = 7 层）的结构。

**P06 原话**（可 grep）：

> The TDONN chip includes one input layer, ﬁve hidden layers, and one output layer, and only one forward propagation is required to obtain the inference results without frequent optical-electrical conversion.

## 3. 机制三：光域做"特征提取"（对你导师课题最相关）

### 这一步在做什么

不是"算完所有东西"，而是**在 ADC 之前把信号压缩**：

```
弱信号 → [光域：降维/滤波/特征提取] → 少通道、高信噪比 → ADC → 数字处理
                ↑
        这一步省掉的是 ADC 的位数和功耗
```

### 为什么这对六分量传感有价值

六分量 = 3 平动 + 3 转动。转动信号极弱（地震级），埋在 RIN、Shupe 效应、热漂移里。

要在低信噪比下量化，ADC 的有效位数（ENOB）要求被顶高。6 通道同时高采样，功耗翻倍。

**光域能帮的**：把 6 路高采样流，在模拟域压成少数几个特征量。
ADC 面对的是慢变、高信噪比的量 → ENOB 要求下降。

### 这与 P01 的关系

P01 把"高精度 DAC/ADC 开销"定义为模拟光计算的头号痛点（原文可 grep）：

> Limited precision of inputs and outputs arises from the finite control resolution and the substantial overhead associated with high-precision DACs and ADCs.

**注意方向**：P01 说的是"光计算被 ADC 拖累"，你说的是"我的系统被 ADC 拖累"。
**同一个瓶颈，从两头看。**

这就是你和黄老师课题的真实交集。

## 4. 光能做什么 / 不能做什么（诚实的边界）

### 光擅长的（有物理优势）

| 能力 | 为什么光有优势 |
|---|---|
| **傅里叶变换** | 一个透镜，光速完成，无算法开销 |
| **大规模并行矩阵乘** | 所有通道同时，延迟 = 光程 |
| **高速低延迟** | 30.2 ps（P06 实测光学时延） |
| **无源运算** | 不需要供电，能量来自光本身 |

### 光不擅长的（必须退回电域）

| 能力 | 为什么光不行 |
|---|---|
| **非线性激活** | 光非线性很弱，需要高功率或特殊材料（P07 就退回电域做） |
| **存储** | 光没有"寄存器"，要么延迟线要么转成电 |
| **精确控制/编程** | 热光调谐慢（μs 级），且漂移 |
| **任意精度** | 模拟量，精度受限于器件噪声与 DAC/ADC |

### 关键判据（P08 原话，可 grep）

> Large optical AI models implemented on PNNs are only commercially feasible if the advantages of optical computation outweigh the cost of their input–output overhead.

**光计算的优势必须大于输入-输出开销。** 这是所有光计算方案的生死线。

## 5. 三条技术路线的信号处理能力对比

| 路线 | 怎么处理信号 | 优势 | 劣势 |
|---|---|---|---|
| **PLC**（平面光转换） | 透镜做傅里叶 + 掩模 | 大规模并行，天生做卷积/相关 | 体积大，难集成 |
| **MZI 网格** | 干涉仪阵列做酉变换 + SVD | 精度高，可编程 | 热光调谐慢，路径损耗 |
| **WDM**（波分复用） | 波长做并行通道 | 通道密度高 | 需要多波长光源 |

（P03 原文定义了这三条路线，可 grep）

## 6. 对黄老师课题的三个可落地方向

| 方向 | 光做什么 | 需要什么 | 风险 |
|---|---|---|---|
| **A 光域前端降维** | 在 ADC 前做一次线性投影 | 一层衍射结构或 MZI 网格 | ADC 是否真是瓶颈（待核实） |
| **B 光域储备池** | 用光纤延迟线 + 非线性读出做时序特征提取 | 光纤环 + 光电非线性 | 训练机制尚不明确 |
| **C 光域相关运算** | 用 4f 系统做快速相关（地震波场匹配） | 空间光调制器 | 自由空间体积大 |

**建议先做 A**，因为：
1. 数学最简单（就是一次矩阵乘）
2. 第一阶段可以纯仿真，零硬件成本
3. 直接对上"ADC 瓶颈"这个可验证的假设

## 7. 自测题（答不上来就回读）

**Q1. 为什么透镜能做傅里叶变换？**
<details>答：因为凸透镜对入射平面波施加二次相位因子，而在夫琅禾费近似下，
前焦面的场分布与后焦面的场分布构成傅里叶变换对。这是几何光学 + 衍射理论的结果，
不需要任何计算。回读 §1</details>

**Q2. 4f 系统做卷积，掩模上放的是什么？**
<details>答：滤波器 h 的频域响应 F{h}。因为卷积定理：x*h 的频谱 = X·H。
在后焦面（频谱面）放一个透过率正比于 H 的掩模，就实现了频域相乘。回读 §1</details>

**Q3. 为什么光域滤波要注意"孔径"？**
<details>答：光域的计算长度由物理孔径决定。孔径不够时，卷积尾部绕回头部，
发生循环卷积混叠（我第一次跑就踩了这个，max diff = 0.655）。
数字域 FFT 会自动补零掩盖这个问题，光域不会。回读 §1 的「一个真实的坑」</details>

**Q4. 为什么单个 MZI 不能实现任意矩阵？**
<details>答：单个 MZI 是酉变换，能量守恒（in=1, out=1，已用代码验证）。
任意矩阵需要"缩放"（奇异值）这个自由度，会改变能量。
所以要 SVD 拆成 U·Σ·V†，其中 Σ 的缩放靠衰减器/放大器实现。
**注意**：整个网格配 SVD 是可以近似任意矩阵的，别说成"MZI 做不了任意矩阵"。
回读 §2 + `cases/P03_*/README.md` §2 第 ④ 条</details>

**Q5. 光计算什么时候值得用？**
<details>答：当光计算的优势（并行度、延迟、能效）大于输入-输出开销（DAC/ADC 转换、
光电转换）时。这是 P08 给出的判据，也是所有方案的生死线。回读 §4</details>

**Q6. 对你导师的六分量系统，光计算最可能帮上哪一步？**
<details>答：ADC 之前的前端降维/特征提取。因为六分量弱信号要求高 ENOB ADC，
6 通道同时采样功耗翻倍；在模拟域先压缩，可以让 ADC 面对更容易量化的量。
**但前提是"ADC 确实是瓶颈"这个假设成立，必须先核实信号带宽与动态范围。**
回读 §3 + §6</details>
