# Product Context — FDTD 超表面研究工作空间

> 本文件是 L1，全仓库最稳定的一层。它一变，所有 Spec / Plan / Task 都要复审。
> 每次会话开始读一次，五分钟入项。
> 最近修订：2026-11-07（产品方针从"论文复现流水线"改为"人定空间、agent 调参闭环"）。

## ① 一句话定位

面向超表面科研人员的本地 Lumerical 工作空间：**人定方向、材料与几何结构，
agent 在锁定的设计空间里用 FDTD 调参闭环，直到产出达标结果。**
论文复现是校准模型可信度的手段，不是产品的终点。

## ② 产品方针（四级分工）

1. **人定方向** —— 要什么功能与指标：R/T/A、相位、效率、带宽、偏振响应；
   目标必须给到可判定的数值与容差。
2. **人定材料与结构** —— 层序、材料、单元拓扑、周期、版图。
   可以多轮调整，也可以走逆向工程；**这部分是人做设计决策，不是 agent 的自由度**。
3. **agent 调参闭环** —— 只在人给定的参数空间内改尺寸 / 角度 / 占空比 / 周期等，
   跑 FDTD、读结果、判断下一步，直到达标，或证明"在给定空间内不可达"。
4. **人做裁决** —— 数值是否可信、结论是否成立、图是否可发表。AI 只给证据。

一句话：**人负责"做成什么"，agent 负责"调到什么"。**

## ③ 两种工作模式（边界不能混）

| 模式 | 目标 | 允许调参 | 不允许 | 产物 |
|---|---|---|---|---|
| **复现 Reproduce** | 对齐论文的图 / 数 | 否。为贴合文献改参数 = 数据造假 | 把拟合说成复现 | 偏差诊断报告（差异本身就是产出） |
| **设计 Design** | 达到人工给定指标 | 是，但只在 `search_space` 内 | 改 `locked` 的材料 / 层序 / 拓扑；隐瞒失败轮次 | 搜索轨迹 + 达标 / 不可达证据 |

红线：

- **Design 模式的调参是优化，不是造假**；但越界即停——要改人锁定的部分，必须先问人。
- **Reproduce 模式仍然禁止调参凑数**。这条不因为新方针而放松。
- 两种模式都必须留下每一轮的：参数、目标函数、`_p0.log`、判断依据、停下的理由。

## ④ 用户与问题

- **用户**：做超表面 / 超材料数值研究的研究生、博后、科研工程师。
- **问题**：
  - 设计空间大，人肉扫几十上百轮，慢且容易漏掉好点；
  - 目标常是多目标（效率 + 带宽 + 相位），手调很难说清"到没到边界"；
  - 逆向工程要反复改结构，改完还得重跑、重判，链路断在"人不在电脑前"；
  - 半年后说不清某一版为什么达标 / 不达标，只剩一张好看的图。

## ⑤ 北极星指标

- 给定方向 + 材料 + 结构族 + 指标后，**agent 在 10 分钟内产出首轮可执行方案**
- **每一轮可追溯率 100%**：参数、目标函数、日志、判断依据齐全
- **"不可达"也要有边界证据**：给出"在给定空间内最好到 X，差 Y"，
  而不是跑不动就放弃
- 任一单元只读 `README.md` 就能接手：100%

## ⑥ MVP 范围（In Scope）

- **目标 spec**：`targets`（指标 + 容差）+ `locked`（人锁死的材料 / 层序 / 拓扑）
  + `search_space`（可调参数及范围）
- 单元胞 / 周期阵列建模与扫参（box / polygon / cylinder / ellipse / sphere / ring；
  drude / constant_nk / constant_eps / builtin / sampled_nk）
- **参数搜索**：先网格 / 坐标下降 / 局部优化，够用就行，不追求花哨算法
- R/T/A 谱与相位提取；收敛判据以 `_p0.log` 的 `Auto Shutoff` 为准
- 每轮结果落 `results/`：csv + 目标函数曲线 + 决策记录
- 三态判定：**达标 / 不可达（附边界证据）/ 需要人改结构**
- 复现模式保留，作为模型校准与技能回归的手段

## ⑦ 非目标（Out of Scope）

- 不做文献综述平台、不做论文排版、不做云端渲染
- 不做多用户在线协作（本仓库是单机 git 工作区）
- **不做无约束自动调参**：agent 不得越过 `locked` 改材料 / 层序 / 拓扑
- **不替人下"物理正确 / 可以发表"的结论**
- 不做 TCAD / 多物理耦合
- 不做伴随法 / 拓扑优化（iter-1）：逆向工程由**人**改材料与结构，agent 负责重跑、判读与记录
- 全器件（透镜、全息相位面）**不在 iter-1**；它是本闭环的后续延伸，不是永久排除

## ⑧ 成功的样子

半年后回看任意一个单元：目标、锁定项、搜索空间、每轮参数与结果、当时的判断，
全部在同一个目录里；能说清"为什么停在这里"，而不是只有一张好看的图。

## ⑨ 与 AI 的分工

| 谁 | 负责 |
|---|---|
| 人 | 方向、材料、结构族、目标与容差、锁定项、最终裁决 |
| agent | 在给定空间内调参、跑 FDTD、读结果、判断下一步、记录证据 |
| 红线 | 不改锁定项；不隐瞒失败轮次；不把"达到目标"说成"物理正确" |
