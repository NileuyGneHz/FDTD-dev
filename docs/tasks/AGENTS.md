# docs/tasks/ — 动作拆分

## 职责

把 plan 拆成"一次会话能做完"的动作。这是 AI 每轮开始唯一该翻的目录。

## 三段

| 目录 | 放什么 | 谁会读 |
|---|---|---|
| `active/` | 正在做的，**最多 3 条** | AI 每轮开头必读 |
| `recent/` | 刚做完，只留结论与验证命令 | 追溯时读 |
| `archive/` | 历史，不再维护 | 默认不读 |

## 格式

```
TASK-<NNN>-<slug>.md
```

```md
# TASK-007 复现 P01 的吸收谱
- 单元：cases/P01_Absorber_Liu2010
- 验收：README §0 的三条判据全绿
- 依赖：spec_p01.json 已通过 validate_spec.py --strict
- 状态：active
```

## 约束

1. **`active/` 超过 3 条就是失控**——要么合并，要么砍。
2. **一条 TASK 只指向一个单元**。跨单元任务先拆。
3. 完成时不删文件，**移到 `recent/` 并补两行**：结论 + 验证命令。
4. **AI 不得自行从 `archive/` 取任务**。
