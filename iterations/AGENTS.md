# iterations/ — 迭代

## 职责

按周期组织"这一段做完了什么、验收过了没有、运行契约变了没有"。

## 结构

```
iter-<N>-<name>/
├─ RELEASE.md           迭代总结、回顾、状态
├─ acceptance.md        验收条件（可判定）
└─ runtime-contract.md  运行契约：模型 / 温度 / 步数 / 工具白名单 / 许可席位
```

## 约束

1. **`acceptance.md` 只写可判定的条件**。"体验好"不是条件，"Δφ 在 1.50–1.60 µm 内偏差 < 5°" 是。
2. **`runtime-contract.md` 是唯一真相源**：`agents/*/agent.yaml` 与 `tools.yaml` 的摘要以它为准，
   两者冲突时先改契约再改配置。
3. **一个迭代一个目录**，结束后不再改，新迭代开 `iter-<N+1>-*`。
4. `RELEASE.md` 每次会话只需追加一行进度，不要等到结营才写。
