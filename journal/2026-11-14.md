## 做了

### 1. 事实核对

`L&E_ws` 就是 `LC_EE_ws` 改名（387 文件 / 144.2 MB / git 头 `8d6046a` / cases `P01…P08`），

### 2. cases 分双轨

```
cases/metasurface/   # 10 包（原 cases/P01…P10 全部 git mv 迁入）
cases/photonic/      # 6 包（L&E_ws 迁入，跳过 P05 / P07）
```

**P05、P07 未搬**：它们的 `paper/` 只有 `.gitkeep`，无 PDF（用户决定整个包删除）。

**P09 搬迁踩坑**：整目录 `git mv` 失败，因为目录里有 **584 MB 的 mp4**（gitignore 忽略但占用文件句柄）。
改为逐文件 `git mv` 后成功；mp4 用 `Move-Item` 单独搬。

**中文路径踩坑**：`git ls-files` 默认把中文转义成八进制（`\344\270\212...`），
导致 `git mv` 找不到文件。必须先 `git config core.quotepath false`。

### 3. 门禁改两层扫描（本轮最关键）

| 文件 | 改动 |
|---|---|
| `tools/check_packages.py` | 新增 `discover_pkgs()`：判据是「目录里有 README.md」而非名字匹配；支持 `cases/metasurface/P01` 与扁平 `cases/P01`；`--pkg` 支持 `metasurface/P03`、`P03`、`metasurface/P`（整轨）三种写法 |
| `tools/check_acceptance.py` | 新增 `iter_pkgs()`，`find_pkg()` 同时认带轨道和不带轨道的写法 |
| `tools/check_reproduction.py` | `FORMAL_PATTERNS` 从 2 条 glob 扩到 4 条，加 `cases/*/*/notes/repro-card.md` |
| `tools/check_skill_contract.py` | `NAME_SHAPE_RE` 从前缀 `fdtd-` 扩到 `fdtd|lit|core|cut|office` |

**为什么必须改**：只搬目录不改扫描逻辑，`check_packages` 会显示 `ERROR=0`
但一个包都没检查（假绿）。`check_reproduction` 更直接——卡片从 2 张变成 0 张，
而门禁仍报 ALL GREEN。
