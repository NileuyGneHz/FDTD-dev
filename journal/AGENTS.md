# journal/ — 会话交接与日志

## 职责

让**下一个人（或下一个 session 的你）能在 3 分钟内接上**。这是篝火模式的"灭火"环节。

## 文件

| 文件 | 内容 |
|---|---|
| `handoff.md` | 当前未完成的事：卡在哪、下一步、涉及哪个单元 |
| `<YYYY-MM-DD>.md` | 当天会话流水：做了什么、试了什么、为什么放弃 |

## 每条日志的结构

```md
# 2026-11-06

## 目标
R01 相位超表面：复现 Fig.3 的 Δφ

## 做了
- 换了 monitor 位置，Δφ 从 12° 变到 178°（→ defects/D-007）

## 卡住
spec 里 `ts` 的口径与论文不一致，等作者回复

## 下次从这接
先按 mid-plane 口径跑一组 ts 扫描
```

## 约束

1. **只写事实与决定**，不写"感觉"。没做的事不写"已完成"。
2. **交接必须写"下次从这接"**，没有这一节的日志等于没写。
3. **一天一个文件**，不建子目录。
4. 日志里的结论如果稳定下来，**上浮**到 `docs/tasks/recent/` 或 `defects/`，日志本身不承担长期记忆。
