### Q2 公式题 —— 论文怎么把"散射"拆开、又怎么定义"无反射透射"？

论文把单个纳米柱的散射场按空间反演宇称拆成偶（even）和奇（odd）两部分，写成对正向（ẑ）和反向（−ẑ）散射的贡献，并给出（主文式 1–4）：

## 参考答案

### A1 机理链

1. **为什么用全介质硅**：金属 nanoantenna 依赖 LSPR，而金属在近红外/通信波段有**显著欧姆损耗**，论文开篇指出金属超表面透射效率"最高不超过 10%，通常更低"。硅是**高折射率、低损耗**介质，共振散射几乎不吸收能量，所以能把透射效率做到 ~90%、偏振转换 ~99%。
2. **硅柱同时给电偶极 + 磁偶极，反向散射相消**：高折射率硅柱被光照射时，内部场增强形成**电偶极**（电子位移）和**磁偶极**（内部位移电流闭合环）。当电偶极与磁偶极的散射在**后向（−ẑ）**恰好等大反相时，后向散射相消 ⇒ **反射≈0**，能量几乎全进前向透射——这就是 Huygens / 广义 Huygens 条件的物理图像（"零后向散射"）。
3. **各向异性 ⇒ 半波片**：硅柱截面是椭圆/矩形，**长轴与短轴**对沿 x、y 的偏振给出不同的共振相位。把柱轴相对入射偏振转 45°，两个正交方向的透射振幅都高（因无损耗），但**相位差被设计成 ≈ π**；两正交分量相对相位差 π 的合成结果就是线偏振方向旋转 90°（半波片）。论文 Fig. 3 实验也确认 `φx − φy` 在宽带内恒为 π。
4. **为什么只靠一对电+磁偶极只能窄带**：单个电偶极共振和单个磁偶极共振各自是**窄带 Lorentz 型**，要让它们在后向相消，必须两者**频率、振幅、相位同时重合（cross）**；重合点本质上是一个频率，稍微偏离任一个共振就失配 ⇒ 反射回升 ⇒ 窄带。论文明确指出 Huygens 条件"occurs only in a narrow spectral range"。

> **要补的基础**：Mie 共振（电/磁偶极）；双折射与波片（retarder）；零后向散射（Huygens）概念。
> **教材锚点**：Hecht《光学》偏振章、干涉章；Novotny & Hecht《纳米光学原理》第 8 章（Mie 共振）。

### A2 散射分解式与广义 Huygens 条件

1. **符号意义**：
   - `E_even(ẑ)`：纳米柱散射场中**空间反演偶（even）**部分在前向（+ẑ）的复振幅（主要由磁型多极贡献）；
   - `E_odd(ẑ)`：**奇（odd）**部分在前向的复振幅（主要由电型多极贡献）；
   - `ẑ`：入射波矢方向（法向）；
   - `φ`：希望透射波相对入射波多出来的相位。
   为什么 `R = |E_even(ẑ) − E_odd(ẑ)|²`：根据偶/奇分量在前后向的对称关系，前向 `E(ẑ) = E_even + E_odd`，后向 `E(−ẑ) = E_even − E_odd`（偶分量不变号、奇分量变号），而反射正比于后向散射幅度，故 `R = |E_even − E_odd|²`。
2. **φ = 0 的验算**：`E_even = E_odd = (e^{i·0} − 1)/2 = (1 − 1)/2 = 0`。
   - `T = |1 + 0 + 0|² = 1` ✓
   - `R = |0 − 0|² = 0` ✓
   说明：当不需要额外相位（φ=0）且偶奇完全相消时，结构就是一块"透明、无反射"的窗。
3. **等效双折射验算**：由 `Δφ = (2π/λ)·Δn·L` ⇒ `Δn = Δφ·λ / (2π·L)`。
   代入 `Δφ = π`、`λ = 1550 nm`、`L = 850 nm`：
   `Δn = π × 1550 / (2π × 850) = 1550 / (2 × 850) = 1550 / 1700 ≈ 0.912 ≈ 0.9` ✓
   与论文 "Δn ≈ 0.9"、且传统材料最高 ~0.3 一致。这凸显超表面用亚波长结构"凭空造出"了远超天然晶体的双折射。

> **要补的基础**：多极展开与宇称；波片 retardance `Δφ` 与双折射关系；复数振幅叠加。
> **教材锚点**：Jackson《经典电动力学》多极展开章；Hecht《光学》偏振章。

### A3 Mie 共振与介质磁偶极子

1. **Mie 理论在说什么**：对均匀球/柱用平面波照射，散射场可严格展开为一系列**多极矩**（电偶极 ED、磁偶极 MD、电四极 EQ……），每一阶是谐振的。高折射率介质粒子（硅 `n≈3.5`）内部场被强烈增强并约束，使其中某些多极（尤其**磁偶极**）进入共振——即"磁 Mie 共振"，与金属里只有电偶极（LSPR）形成对比。
2. **介质怎么出现磁偶极**：在电介质球里，入射磁场感应的**内部位移电流**会沿闭合路径流动（因为高折射率把场"困"在颗粒内），形成一个等效**电流环**——电流环就是磁偶极矩。定性上它等价于一个 LC 谐振回路：位移电流 + 内部电场储存的能量共振。金属颗粒内部场被表面等离激元主导，位移电流环难以形成，所以主要是电偶极。
3. **为什么用 poly-Si 且低损耗**：论文明确 "negligible optical losses"。若介质有吸收（损耗型半导体），散射能量会被介质本身吃掉，**透射与偏振转换效率直接被吸收项压低**——`T + R + A = 1` 里的 `A` 不再是≈0，~90% 透射、~99% 转换这两个卖点都会垮。所以"无损耗"是这篇文章能赢过金属的前提。
4. **一句话**：磁 Mie 共振提供了天然的**奇宇称（磁型）散射源**，与电偶极（偶宇称）配对后，两分量可在后向相消 ⇒ 介质里"零后向散射 / Huygens"几乎是结构可调的必然结果，而金属缺少磁型共振源，后向相消难实现。

> **要补的基础**：Mie 散射理论；位移电流与磁偶极；复折射率与吸收损耗。
> **教材锚点**：Bohren & Huffman《小颗粒的光散射》（Mie 理论）；Novotny & Hecht 第 8 章；Jackson《经典电动力学》。

### A4 为什么多极柱、为什么这些尺寸

1. **一对电+磁偶极为何窄带**：Huygens 条件要求 `E_even = E_odd`（后向相消），若偶、奇分量**各自只由一个共振**提供，则必须**电偶极共振与磁偶极共振在频率、振幅、相位上同时重合（cross）**；共振交叉在数学上是一个点频率，偏离即失配 ⇒ 反射回升 ⇒ 窄带。论文原话："the only condition ... is if these two resonances cross"，"crossings inherently occur at single wavelengths"。
2. **多极为什么放宽带**：改用多极纳米柱后，`E_even` 和 `E_odd` 各自是**多个多极的线性组合**（ED + MD + HOM）。广义 Huygens 条件 `E_even = E_odd` 于是变成"多极之间的平衡"，**不再要求某两个共振等幅等宽**；不同多极在不同频率接力补偿，使后向相消在宽频带维持 ⇒ 宽带。论文："Eq. (4) becomes a balance between multipoles, and does not require resonances of equal amplitude and spectral width."
3. **柱高 c=860 nm 的作用**：柱越高（与波长可比拟），能容纳越多的**高阶多极（HOM）**模式；若只有 200 nm 的薄片，高阶模式被几何截断，退回到"双极"情形 ⇒ 宽带优势消失，回到窄带/低效。论文也强调用纳米柱（而非纳米盘）正是"to allow more multipolar modes"。
4. **周期 D=750 nm 必须亚波长**：若 `D` 大于波长，阵列会向**更高的衍射级（grating orders）**辐射，破坏"每个单元只做局域相位/偏振调控"的假设，能量跑进非 0 级、透射与偏振纯度都崩。亚波长周期保证只有 0 级传播，结构表现为"均匀有效介质/超表面"而非光栅。

> **要补的基础**：Huygens 超表面与共振交叉；多极平衡；亚波长周期与衍射级。
> **教材锚点**：Novotny & Hecht 第 8 章；Yu & Capasso 综述（Nat. Mater. 2014）超表面章。

### A5 宽带 vs 窄带 A/B 对照实验设计

1. **自变量与冻结量**
   - 自变量（直接复用论文 S1 两组几何）：
     - **A（宽带）**：`a = 285 nm, b = 450 nm, c = 860 nm, D = 750 nm`（方形晶格硅柱）。
     - **B（窄带）**：`a = 160 nm, b = 470 nm, c = 1080 nm, D = 950 nm`（方形晶格硅柱）。
   - 必须冻结：材料用 **Palik 晶硅**介电常数、石英衬底、`c` 在两组内各自固定、正入射、网格（mesh accuracy + 柱体 mesh override）、PML、监视器位置、波长范围（如 1400–1700 nm）与点数、分别跑 x 偏振与 y 偏振两次。**只允许几何参数变**。
2. **输出量与压缩**
   - 每条曲线输出：共偏振透射 `T_co(λ)`（偏振轴平行柱长/短轴）与交叉偏振透射 `T_cr(λ)`（输入 x、分析 y），以及各自透射相位 `φx(λ)`、`φy(λ)`。
   - 压成可比较的数字：
     - 用论文的 **100:1 对比度带宽**：找 `T_cr / T_co ≥ 100` 的连续波长区间宽度 `Δλ`；
     - 以及 **`φx − φy` 落在 `π ± 10%`** 的波长区间宽度（论文 Fig. 4b 的容差 `λ/20`）。
   - 报告两行表：`几何 | 100:1 带宽 Δλ | π相位差维持带宽`。
3. **证伪设计（判断是物理还是数值误差）**——至少两条独立判据：
   - **判据 A（能量守恒校验）**：对每个结构检查 `T_co + R_co + A ≈ 1`（硅低损耗 ⇒ `A≈0`，应 `T+R≈1`）。若总和明显 < 1，说明有能量漏进 PML 或监视器漏采，结论不可信。
   - **判据 B（网格收敛）**：把 mesh accuracy 提高 2 级（或柱体 mesh override 减半），重跑 A、B 的带宽。若"宽带比窄带宽 8 倍"的趋势在加密后**稳定保持**，是物理效应；若带宽数值随网格大幅漂移，说明未收敛。
   - **附加判据 C（对称性自检）**：结构对 x/y 有定义好的各向异性，检查 `T_co`（沿两轴）与 `T_cr` 是否符合预期（交叉项非零、共偏振在 45° 输入下被抑制），并可加一次周期边界 (PBC) 与同尺寸但更大 supercell 的对照，确认无伪衍射级混入。
4. **预期**：宽带几何的 100:1 带宽应**远大于**窄带几何。论文给出具体数字：**宽带 152 nm、窄带 19 nm，相差 8 倍**。物理上这是因为宽带几何靠多极平衡维持后向相消，窄带几何只靠一对共振交叉。若你的 FDTD 跑出"两者带宽差不多"，先查网格/周期边界而非怀疑论文。

> **要补的基础**：受控变量法（对照实验）；FDTD 收敛性判据；能量守恒与衍射级判据。
> **教材锚点**：本项目 `SKILL.md` §5（结果与验证）、§7（排错）；Novotny & Hecht 第 8 章。
