## 题目

### Q1 物理现象题 —— 同一片超透镜，为什么换成左旋圆偏振入射就从"凸透镜"变成"凹透镜"？

论文说："The metamorphosing phase shift, ranging from 0 to 2π, is realized by a metasurface consisting of an array of plasmonic dipoles … By adjusting the orientation angle θ of the individual dipole antennas, we can obtain the required phase shift … as the local abrupt phase change is simply given as Φ = ±2θ, with the sign determined by the combination of the incidence/transmission polarizations … the sign of the phase discontinuity can be reversed by controlling the helicity of the input and detected CP light."

1. 为什么必须是**圆偏振（CP）**光入射，而且只看"转换到相反旋向"的那部分？线偏振入射行不行？

3. 把偶极子沿 x 方向按 `θ(x)` 排成阵列，为什么整体就成了一片透镜？RCP 入射时为什么是"会聚"（正透镜），LCP 入射时为什么变成"发散"（负透镜）？
4. 论文实测：RCP 入射时 Lens B 在透射侧 z = +60 mm 出现实焦线、Lens A 在入射侧 z = −61 mm 出现虚焦线。为什么同一片、只换旋向，焦点的"实/虚"和"正/负"就整个翻过来了？

### Q3 前置基础题 —— 几何相位（Pancharatnam–Berry phase）：为什么"转一下"就给圆偏振光加 2θ 相位？

论文 Methods 用偶极矩矩阵（式 2、式 3）证明了圆偏振基下散射会带 `exp(±i2θ)`。这件事更底层的解释是**几何相位**：一个"互易"的散射体绕 z 轴转 θ，其对相反圆偏振的散射振幅就获得 `e^{∓i2θ}` 因子。

请回答：
1. 一个沿自身主轴（u,v）具有 Jones 矩阵 `M` 的互易元，整体绕 z 转 θ 后，全局坐标下的 Jones 矩阵是 `R(−θ)·M·R(θ)`（`R(θ)` 是旋转矩阵）。圆偏振本征态满足 `R(θ)|σ⟩ = e^{∓iθ}|σ⟩`（`σ = ±1` 标记左右旋）。由此推导：入射为某一旋向、散射到相反旋向时，会多出一个什么相位因子？

## 参考答案

### A1 机理链

1. **为什么必须圆偏振**：论文要利用的是"入射 CP → 散射成相反旋向 CP"这一通道（Methods 把偶极矩按 CP 基分解，得到 `exp(±i2θ)` 那一项）。线偏振可拆成 LCP+RCP 两个等幅分量，各自都会被偶极子带上不同符号的几何相位，合成后几何相位**相互抵消**，只剩普通共振相位，无法干净地做"旋向相关"的透镜。所以必须纯化到单一旋向入射、并只检测相反旋向出射。
2. **单个偶极子为何给 2θ**：互易偶极子转 θ 后，对"相反圆偏振"散射通道的 Jones 矩阵带一个整体相位 `e^{∓i2θ}`（即几何相位）。它来自旋转的"拓扑"性质——只取决于转过的角度、与局域共振/波长/材料几乎无关，所以振幅能保持均匀、相位可在 0→2π 连续覆盖。
3. **阵列变透镜**：沿 x 把每个偶极子的取向角设成 `θ(x)`（式 1），整片界面就获得一个随位置变化的突变相位 `Φ(x) = ±2θ(x)`。这正是一片"薄透镜"需要的相位轮廓：中心与边缘相位差让出射波前弯成会聚（或发散）球面。RCP 入射取 `+` 号 → 相位轮廓对应**正透镜**（会聚）；同一片换 LCP 入射，`±` 反号 → 同一 `θ(x)` 给出 `−Φ(x)`，即相位轮廓整体取反，变成**负透镜**（发散）。
4. **实/虚焦为何翻转**：正透镜把平行光会聚到透射侧实焦面（z = +f）；负透镜让光线"看似从"入射侧一点发出，焦点是虚的（z = −|f|）。论文实测 Lens B（对 RCP 为正）在 z = +60 mm 有实焦线、Lens A（对 RCP 为负）在 z = −61 mm 有虚焦线；把入射从 RCP 翻成 LCP，`Φ` 变号，A、B 的实/虚焦随之互换——这就是"同一片、换旋向即翻极性"的实验证据。

> **要补的基础**：圆偏振的 Jones/球谐表示；几何相位（PB 相位）；薄透镜相位轮廓。
> **教材锚点**：Hecht《光学》偏振章；Hasman et al., Appl. Phys. Lett. 82, 328 (2003)（PB 相位衍射光学，参考文献 24）；Yu & Capasso, Science 2011/2012（界面相位不连续）。

### A2 透镜相位分布与双极性

1. **符号解释**
   - `k0 = 2π/λ`：自由空间波矢（λ = 740 nm）。
   - `f`：透镜焦距；`|f|` 取绝对值是为了让正负焦距共用同一公式。
   - `x`：偶极子沿聚焦方向（x）离轴心的位置。
   - `θ(x)`：该位置偶极子相对 x 轴的旋转角（即"刻进去"的几何量）。
   - `Φ = ±2θ`：该偶极子对相反圆偏振出射光施加的局部突变相位。
   - `∓` 符号：`+` 对应**正（凸）透镜**、`−` 对应**负（凹）透镜**，**这是针对 RCP 入射而言**；对 LCP 入射上下号反过来（论文："the opposite holds for a LCP incident wave"）。
2. **验算（边缘 x = 40 µm，f = +60 mm = 60000 µm，λ = 740 nm）**
   `√(f²+x²) − f = √(60000² + 40²) − 60000 ≈ 60000.01333 − 60000 = 0.01333 µm = 13.3 nm`
   `k0 = 2π/740 nm = 0.00849 nm⁻¹`
   边缘旋转角：`θ_edge = (k0/2)·13.3 nm = 0.5 × 0.00849 × 13.3 ≈ 0.0565 rad`
   边缘相位：`Φ_edge = 2θ_edge ≈ 0.113 rad`？——**注意**：上式里 `θ` 已含 `k0/2`，所以 `Φ_edge = 2θ_edge = k0·13.3 nm = 0.00849 × 13.3 ≈ 0.113 rad`。换算成度：`0.113 rad × 180/π ≈ 6.5°`。
   即整片孔径内相位从中心 0 单调爬到边缘约 6.5°（对应 f = 60 mm 的大焦距弱透镜；若焦距更短，跨度会更大）。数值量级与论文图 3c/d 的相位斜坡一致。
3. **0→π 覆盖 0→2π 与双极性**：`Φ = 2θ`，所以 `θ ∈ [0, π]` ⇔ `Φ ∈ [0, 2π]`，旋转角扫满半圈就获得全相位范围。关键在符号：`Φ_RCP(x) = +2θ(x)`，而 `Φ_LCP(x) = −2θ(x) = −Φ_RCP(x)`。一片物理结构（固定的 `θ(x)`）对两种旋向给出**符号相反**的相位轮廓，即焦距 `+f` 与 `−f` 互换——这就是"双极性"的数学本质，不需要任何结构改动。

> **要补的基础**：薄透镜的相位函数 `k0(√(f²+x²)−f)`；几何相位符号随旋向翻转。
> **教材锚点**：Hecht《光学》透镜/波前章；Hasman 2003（参考文献 24）。

### A3 几何相位（Pancharatnam–Berry phase）

1. **推导**：全局 Jones 矩阵 `M_global(θ) = R(−θ)·M·R(θ)`。圆偏振本征态满足 `R(θ)|σ⟩ = e^{∓iθ}|σ⟩`（σ = +1 左旋、−1 右旋，符号约定依论文）。入射为 `|σ⟩`、要求散射到相反旋向 `|−σ⟩` 的振幅为
   `⟨−σ| M_global(θ) |σ⟩ = ⟨−σ| R(−θ) M R(θ) |σ⟩`
   因为 `R(θ)|σ⟩ = e^{∓iθ}|σ⟩` 且 `⟨−σ|R(−θ) = e^{±iθ}⟨−σ|`（注意 `⟨−σ| = (R(θ)|σ⟩)†` 关系），整体得因子 `e^{±iθ}·e^{∓iθ} = e^{∓i2θ}`。即相反圆偏振通道获得 **`exp(∓i2θ)`** 相位——论文 Methods 式 (3) 的 `exp(±i2θ)` 正是此意（符号依 LCP/RCP 组合而定）。
2. **相对共振相位的优势**：共振相位靠调天线长度改变 LSPR 频率，振幅会随长度剧烈变化、且强色散（相位随波长跑得快 → 窄带）；几何相位只由旋转角决定，**振幅均匀**（论文强调"without sacrificing the uniformity of amplitude"）、且因与共振弱耦合而**宽带**。这正是论文能覆盖 740–810 nm 并做"双极性"的关键。
3. **为何线偏振无效**：线偏振 = `(|L⟩+|R⟩)/√2`。两分量各自带 `+2θ` 与 `−2θ`，合成后几何相位**相消**，只留下与旋转无关的共振相位，所以一片按几何相位设计的阵列对线偏振不会呈现旋向相关的聚焦/极性翻转。这也正是 Q5 证伪判据的根据。
4. **相对 Hasman 2003 的进步**：Hasman 用 PB 相位在**远红外**做了偏振相关聚焦透镜，但当时**没有在可见光**实现、也未直接观测到凹透（虚焦/缩小像）。本论文首次在**可见/近红外**（740 nm）用等离激元偶极子做出双极性透镜，并靠实/虚焦与放大/缩小成像（实测 1.45 / 0.87）**直接证实**两种极性都存在——论文引言与讨论专门点明这一点。

> **要补的基础**：Jones 矩阵与旋转；圆偏振基；几何相位与立体角。
> **教材锚点**：Hecht《光学》偏振章（Jones 计算）；Hasman et al., Appl. Phys. Lett. 82, 328 (2003)；Novotny & Hecht 第 8 章。

### A4 为什么旋转角编码、S=400 nm、转换率仅 5%

1. **旋转角 vs 共振相位**：早期纳米缝/纳米孔透镜靠波在波导模里传播**累积**相位，金属膜厚度有限时总相位远小于 2π（论文："phase range well below 2π with realistic thickness"）。几何相位用"转 θ"直接映射 `Φ = 2θ`，θ 转半圈即得全 2π、**不依赖传播长度**、振幅还均匀。所以本设计选旋转角编码，天然避开"厚度不够相位不够"的死结。
2. **为什么 S = 400 nm 亚波长**：阵列周期必须小于波长（λ = 740 nm），否则会出现高阶衍射级（grating order，`sinθ_m = mλ/S`）。`S < λ` 时除 `m = 0` 外均被截止，只有 0 级（异常）透射存在，透镜才是"单束"的；若 `S = 900 nm > λ`，会冒出 ±1 级杂散衍射，焦点被污染。论文取 400 nm 正是为了压住衍射级。
3. **偶极尺寸与 5% 转换率**：200×50 nm 的 Au 偶极子被设计成纵向共振 ~970 nm、横向共振 ~730 nm，使其在工作波段（740/810 nm）附近有较强的圆偏振转换耦合。但论文实测**圆偏振间转换功率仅 ~5%**。论文明确说这是"technical issue rather than a fundamental limit"：原因包括偶极密度不够、天线共振波长与工作目标波长未精确对齐、部分能量散射到非转换通道/吸收。改进方向正是"increase the density of the dipoles"和"better alignment of the resonance wavelength"——也就是提高偶极面密度、并把共振对到工作 λ。

> **要补的基础**：衍射级与光栅截止条件；局域表面等离激元共振；耦合/转换效率。
> **教材锚点**：Hecht《光学》衍射/光栅章；Novotny & Hecht 第 8 章（偶极子共振）。

### A5 同片 RCP vs LCP 双极性 A/B 对照

1. **自变量与冻结量**
   - A 组：按式 1 取 `+` 号设计的超表面（即 Lens B 类、对 RCP 为正透镜），入射 **RCP** 平面波，λ = 740 nm，正入射。
   - B 组：**同一片结构**，仅把入射旋向换成 **LCP**（其它全同）。
   - 必须冻结：几何（S=400 nm、偶极 200×50×40 nm、θ(x) 分布、ITO/玻璃基底）、Au 材料模型、λ=740 nm、网格（mesh accuracy + 偶极区 mesh override）、PML 类型层数、监视器位置与采样、光源振幅。只允许"入射旋向"这一项不同。
2. **输出量与压缩**
   - 输出：透射侧沿传播方向（z）的纵向强度扫描 `I(x=0, z)`，以及焦平面处横向强度剖面 `I(x, z=z_f)`。
   - 压成数字：①**焦点位置** `z_f`（纵向扫描峰值所在 z；A 组应为正、B 组焦点为虚即纵向扫描无实峰、需由相位/反向延拓判定）；②**焦斑横向 FWHM**（横向剖面半高全宽）。报告两行：`入射旋向 | z_f | FWHM`。
3. **证伪设计（判断是 PB 物理还是数值误差）**——至少两条独立判据：
   - **判据 A（线偏振不聚焦）**：额外跑一组**线偏振**入射（同结构）。因几何相位在线偏振下抵消，应**看不到清晰的聚焦**（只有共振相位、无极性翻转）。若线偏振组也出现与 RCP 相同的强焦点，说明焦点来自网格/PML 伪像而非 PB 相位——A/B 的极性差才可信。
   - **判据 B（网格收敛）**：把 mesh accuracy 提高 2 级（或偶极区 mesh override 减半），重跑 A、B。若焦点位置 `z_f` 与 FWHM 随加密基本不动，说明已收敛、是物理效应；若大幅漂移，结论不可信。
   - **附加判据 C（能量守恒与 CP 占比）**：检查 `T + R + A = 1`；并用 CP 分析器确认透射中"相反旋向"分量占比（论文量级 ~5%）。若总能量不守恒，监视器/PML 设置有误。
4. **预期**：A 组（RCP）在透射侧 `z ≈ +f`（正透镜、实焦）出现会聚斑；B 组（LCP）同一片变为负透镜，光线发散、透射侧无实焦（虚焦在入射侧 `z ≈ −f`）。两组焦距满足 `z_f^B ≈ − z_f^A`，即 `±f` 互换——这正是论文 Figure 4 用 RCP/LCP 同片得到实焦/虚焦互换所证实的双极性。

> **要补的基础**：受控变量法（对照实验）；FDTD 远场/近场与收敛判据；圆偏振态分析。
> **教材锚点**：本项目 `SKILL.md` §5（结果与验证）、§7（排错）；Hecht《光学》偏振章。
