## 2. 第一讲核心知识

### 2.1 物理量定义（基础中的基础）

**「率」是一种比值（实数，0~1）**

| 量 | 定义 | 公式 |
|---|---|---|
| 透射率 | 透射光强 / 入射光强 | `T = I_T / I_in = \|E_T\|² / \|E_in\|²` |
| 反射率 | 反射光强 / 入射光强 | `R = I_R / I_in = \|E_R\|² / \|E_in\|²` |
| 吸收率 | 三者守恒 | `A = 1 − T − R`，即 `T + R + A = 1` |

**「系数」是乘积中的常数（复数，含相位）**

```
E_in = |E_in|·exp(−iφ_in)      E_T = |E_T|·exp(−iφ_T)      E_R = |E_R|·exp(−iφ_R)

E_T = t·E_in   →   t = |E_T|/|E_in| · exp[−i(φ_T − φ_in)]      |t|² = T
E_R = r·E_in   →   r = |E_R|/|E_in| · exp[−i(φ_R − φ_in)]      |r|² = R
```

> ⚠️ **只有透射系数、反射系数，没有"吸收系数"**（吸收是功率耗散，不是相干叠加）。
> **系数保留相位，率丢失相位**——做超表面**相位工程**必须用复数系数，不能用率。

**S 参数 = 端口的透/反射系数**

```
光从端口 0 一侧入射：
  S00 = 端口 0 收到端口 0 的场 = r      →  |S00|² = R
  S10 = 端口 1 收到端口 0 的场 = t      →  |S10|² = T
```

### 2.4 我的第一个仿真（课程示范案例）

**结构**：

```
        550 nm 周期，正方形阵列
        ┌──────────────┐
        │   L 形 Si    │  ← 高 250 nm
        └──────────────┘
        ═══════════════════
           BaF₂ 基底 (n = 1.469)
```

- Si 谐振器：**L 形**（立方体切掉一角），高度 **250 nm**，外形尺寸标注 **360 nm × 140 nm**，
  顶面还剩 **280 nm**，缺口 **80 nm**（即"破缺对称"的那个 notch）
- 阵列周期：**550 nm**
- BaF₂ 折射率：**1.469**（低折射率基底 → 保留谐振器的 Mie 模式）
- Si：直接取 FDTD 材料库中的材料

**光源与监视**：
- **x 方向偏振**的平面光，**从上往下**照射
- 计算任务：① 反射率谱（**900–1100 nm**）② **960 nm** 时 Si 附近的电场分布

**结果特征**：

| 波长 | 反射率 |
|---|---|
| 900 nm | ≈ 0.42（上升沿） |
| 950–1000 nm | **高反射平台 0.8~0.95** |
| 1100 nm | ≈ 0.2（下降） |

960 nm 的电场分布图显示：**场集中在 L 形 Si 的缺口附近**，呈明显的局域增强图案。

**课程留的练习**：改一个结构尺寸重算，共振会移动（论文实例中移到 **@972.5 nm**），
此时需要补做 (3) 仿真时间 和 (8) Auto shutoff min。

> ★ **这个单元胞就是配套论文里 SOI 实验的结构**：论文正文写 Si 谐振器 *nominal side length* **280 nm**、
> 阵列间距 **550 nm**、SOI 硅层厚 **250 nm** —— 与 PPT 的标注逐个对上。
> 也就是说，第一讲的练习本质是**论文实验部分的单元胞仿真**。

| 项 | 内容 |

| 期刊 | **ACS Photonics 2016, 3, 2362−2367** |
| DOI | 10.1021/acsphotonics.6b00556 |
| 收稿/上线 | 2016-08-02 投稿；2016-10-25 上线 |

### 3.2 要解决的问题

超表面的**共振太宽 → Q 值太低**，限制了传感、滤波、光调制等应用。

两条技术路线的问题：

- **金属超表面**：红外/光频下**欧姆损耗**大 → 共振宽
- **介质超表面**：损耗降下来了，但**与外部场耦合强（辐射损耗大）** → 共振**依然宽**

已有的高 Q 方案（EIT / Fano 共振）：需要单元胞内有**多个近场耦合的介质结构**（如 oligomer 团簇），
**近场耦合的可靠控制对加工容差要求极苛刻**。

### 3.3 核心创新

> **单元胞里只放一个谐振器，靠「破缺对称」在谐振器内部引入亮-暗模耦合。**

- 关键区别：是 **intraresonator（谐振器内）** 模耦合，**不是 interresonator（谐振器间）**耦合
- 工程好处：**不需要制造深亚波长间隙**，大幅降低加工难度
- 可缩放性：从**近红外一直到射频**都适用

### 3.4 物理机制（论文最值得学的部分）

**Step 1 —— 高对称谐振器的模式结构**

孤立立方体谐振器（高对称）支持**正交且简并**的模组：

```
电偶极子：px, py, pz
磁偶极子：mx, my, mz
（外加高阶多极子）
```

**Step 2 —— 阵列中哪些模能被激励**

在亚波长周期的阵列里，**只有面内（横向）的偶极模**能与正入射波耦合：

```
亮模（bright）：px        → 既能辐射衰减(radiative)，也能非辐射衰减(nonradiative)
暗模（dark）  ：mz        → 只有非辐射衰减
```

亮模 px 是"宽"共振的来源。

**Step 3 —— 破缺对称引入耦合**

切掉立方体的一个角（notch），几何对称性被打破：

```
亮模 px  ──(破缺对称诱导耦合)──>  暗模 mz（纵向磁偶极）
```

论文的物理解释：谐振器两部分沿 x 方向**宽度不同** → 两个等效电偶极子强度略有差异 →
x 偏振波激励下，这个不对称在谐振器中心附近产生**z 方向的磁场** → 耦合到 mz。

> 完整立方体谐振器**没有这个激发通道** —— 这就是"破缺对称"的必要性。

**Step 4 —— 为什么 Q 高**

- **孤立谐振器**：mz 可以自由辐射 → 共振**宽**
- **置于二维阵列中**：谐振器位置的**局部场驱动项补偿了正常的辐射衰减** →
  只剩（很小的）非辐射损耗 → **Q 变高**

两个模**干涉** → 得到 Fano 共振。

**Step 5 —— 第二个 Fano 共振**

更高能量处还有一个，机制类似但模的角色互换：

```
亮模 = 面内磁偶极 my  ，  暗模 = 纵向电偶极 pz   （论文未深入讨论）
```

### 3.5 证据链：多极子分解"数值实验"

这是论文方法论上最漂亮的一段，值得记录：

1. 仿真整个阵列的**共振响应**（为简化去掉基底），在中心谐振器外放一个**虚拟盒子**
2. 用**"电场驱动条件"**（两束相向传播的平面波，抵消中心处入射磁场）→ 选择性地只激励亮模 px
3. 用 **Love 等效原理**，把盒内源替换为总切向场导出的**等效电磁表面电流**
4. 移走阵列中其余谐振器，用**近远场变换**计算表面电流辐射的远场
5. 利用多极子场在单位球上的**正交性**，把远场分解为**多极子分量**（含全部四极子贡献）

**结论（Figure 3）**：

| 位置 | 主导多极子 |
|---|---|
| 共振频率两侧 | **px**（x 向电偶极子）主导，符合预期 |
| 共振处 | **px 急剧下降**，**mz 急剧上升**，比其它多极子强近 **2 个数量级** |

同时 py 与 Mzx（z-x 磁四极子）也被激发，但两者在前后向**几乎相消**，
加上 px 的骤降 → 解释了共振处**高透射、低反射**。
py 与 Mzx 相消不完全 → 透射波有**小的去偏振**（SI 补充）。

### 3.6 阵列尺寸效应（重要工程结论）

论文对比了孤立谐振器与 3×3 / 5×5 / 7×7 / 9×9 阵列（无基底）：

| 阵列 | 现象 |
|---|---|
| 孤立 | **无窄 Fano 共振**（纵向偶极可自由辐射），场分布像 px 激励 |
| 3×3 | Fano 共振**很弱**，内部开始出现场循环 |
| 5×5 | **清晰的 Fano 共振**，内部谐振器明显呈现 mz 对应的电场环流 |
| 7×7 / 9×9 | 经历强场增强的内部谐振器增多；**边缘谐振器增强较弱**（局部场不同、可辐射更多） |

- 中心谐振器的磁场增强随阵列增大**急剧上升**，在 9×9 时**开始饱和**；磁增强量级 **~200**
- ★ **结论：实现稳健 Fano 共振所需的阵列尺寸其实很小**（≈ 5×5）

> 💡 **对我们的直接价值**：不必盲目加大仿真区域。**小阵列即可捕获物理**，
> 这能显著缩短单次仿真时间和内存占用 —— 对要做参数扫描的场景是硬收益。

| 材料 | 结构 / 工艺 | 周期 | 结果 |
|---|---|---|---|
| **Ge（仿真）** | 立方体边长 2.53 μm，切一个角；BaF₂ 基底 | 4.2 μm | **Q ≈ 1300** @ **~10.8 μm**（中红外）；共振处场增强数个数量级 |
| **Si（实验）** | SOI，硅层厚 **250 nm**，边长 **280 nm**，e-beam 光刻 + RIE | **550 nm** | **Q ≈ 350** @ **998.8 nm**；NA = 0.14/0.26/0.4 三种物镜下**均可见**（对角入射稳健） |
| **GaAs（实验）** | 外延 GaAs，借用面发射半导体激光器的隔离工艺；标称 **270×270×300 nm³**，缺口 x=70 nm、y=190 nm，缩放因子 s = 0.89/0.92/0.95 | **470 nm** | **Q ≈ 600**（fwhm **1.6 nm**）—— 该波段**文献最高** |

**其他实验细节**：

- Si 实验的实测谱与仿真谱形状相似但有**整体波长偏移**，归因于设计/加工的**尺寸差异**；
  短波长 Fano 共振形状的差异，怀疑是仿真中 **SOI 埋氧层厚度不准** ——
  埋氧层形成**低精细度 etalon**，与 Fano 行为干涉，调制了共振整体形状
- GaAs 是**直接带隙**，近红外残余吸收比间接带隙 Si 更小 → 理论上能得到更高 Q（实验证实 600 > 350）
- 低温反射测量显示 Fano 位置移动，但**没有进一步变窄**

### 3.8 论文结论与应用

- 破缺对称 → **单元胞单谐振器**即可获得高 Q Fano 共振，宽频段可缩放，半导体材料易实现
- Si Q≈350、GaAs Q≈600（该波段最高）
- 展望：GaAs 有源/非线性特性 → 激光器、光电探测器、调制器、非线性频率转换器、传感器

### 3.9 ★ 对本人工作的三点启示

1. **工具链一致，方法可直接迁移**：论文用的是 **Lumerical FDTD Solutions**，
   且文中"参数扫描"正是我们要自动化的痛点。论文是**同一工具**下的完整范例。
2. **"对称性破缺"是相位工程的思想同源**：
   本文用破缺对称激发暗模 mz；而几何相位（PB）用**旋转角 θ** 破缺面内对称性，得到相位 `Ψ = ±2θ`。
   两者都属于"**用结构对称性换取额外光学自由度**"这一族思路。
3. **全介质路线更贴合我们的材料库**：本论文是**全介质**（Ge/Si/GaAs，Mie 共振），
   而我方材料库是 **TiO₂ + Si₃N₄（全介质）+ 6 种液晶**；
   相比之下导师先前给的 Ding 2015 是**金属等离激元**（Au/SiO₂）。
   → **两篇论文代表两条技术路线，本课程的这篇更接近我们的材料体系。**

## 附录 A：名词速查

| 术语 | 含义 |
|---|---|
| **Fano 共振** | 窄带非对称谱线，源于离散态与连续态（或亮模与暗模）的干涉 |
| **亮模 / 暗模** | bright：能与入射波直接耦合、可辐射衰减；dark：不能直接耦合、只有非辐射衰减 |
| **Q 值** | 品质因数，`Q = λ₀ / Δλ`（λ₀ 共振波长，Δλ 半高全宽 fwhm） |
| **Mie 模** | 高折射率介质谐振器的内部共振模式（电/磁偶极、四极子等） |
| **破缺对称** | 人为破坏结构的高对称性，以引入原本禁戒的模耦合 |
| **PML** | 完美匹配层，吸收边界条件，避免边界反射污染结果 |
| **Auto shutoff min** | 场衰减到该阈值即提前终止仿真（省时间，但要保证收敛） |
| **BFAST** | Lumerical 的宽带固定角平面波光源（斜入射用） |
| **Bloch 条件** | 周期性边界条件下斜入射的相位关系；宽光谱斜入射时可能失效（第 043 讲重点） |
| **PCR** | Polarization Conversion Ratio，偏振转换效率 |
| **广义斯涅尔定律** | 相位梯度界面上的反射/折射定律修正（第 047/049 讲） |
