## §4 结论与偏差

**结论：Fig.1b/1c 基本复现，Fig.3b 相位判据成立。**

| 量 | 论文 | 本次（800–1600 nm） | 判定 |
|---|---|---|---|
| `R_co` 均值 / 最大 | ≈0 | 0.0131 / 0.0305 | ✅ / ✅ |
| `R_cr` 平台 / 带边最低 | ≈0.92 / ≈0.78（读图） | 0.9031 / 0.8101 | ✅ |
| `PCR` 均值 / 最小 | >95% | 98.58% / 96.68% | ✅ |
| PCR>95% 带宽 | 805–1672 nm | 790–1660 nm | ✅ |
| 相对带宽 `W_B` | ≈70% | 71.0% | ✅ |
| `Δφ_uv` 均值 | ≈π（0.9π–1.1π） | 181.7° ± 13.5° | ✅ |
| `Δφ_uv` @1.0 µm | ≈171°（读图） | 164.4° | ✅ |
| 收敛末值 | — | 8.82e-6 < 1e-5 | ✅ |

- 剩余差异：`R_cr` 平台比论文低约 1.7 个百分点，`R_co` 高约 1.3 个百分点，`Δφ@1.0 µm` 比读图值低约 7°；
  更可能来自 10 nm 网格对 80 nm 金砖尖角的离散、未计 Ti 粘附层、FEM/FDTD 差异。
  20 nm 粗化对照直接崩到 R_co 56%、PCR 30%，证明 10 nm 已接近该几何的可用下限；5 nm 细化未完成。
- 相位整带均值 181.7°，`cos` 均值 −0.972；1.0 µm 处 164.4°，在论文黑线的起伏范围内。
- **未做**：没有为了抬高 `R_cr` 改 l1/l2/ts；没有把相位拟合成 180°。

完整证据见 [`results/repro_p03/repro_report.md`](results/repro_p03/repro_report.md)。
